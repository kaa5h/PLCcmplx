   WINDOWS USERS:
   1. Double-click: setup_and_run.bat
   2. Follow the prompts
   3. Open browser to: http://localhost:5000

   MAC/LINUX USERS:
   1. Open Terminal in this folder
   2. Type: ./setup_and_run.sh
   3. Follow the prompts

📋 WHAT YOU NEED BEFORE STARTING:

   ✓ Python 3.8 or newer
     Download: https://www.python.org/downloads/

   ✓ Anthropic API key + Payment Method (REQUIRED)
     Get it: https://console.anthropic.com/

     ⚠️  IMPORTANT: This is NOT FREE
     - You MUST add a credit card or payment method
     - Minimum credit purchase: $5 USD
     - Credits don't expire

     Steps to get API key:
     1. Go to console.anthropic.com
     2. Sign up for an account
     3. Go to "Billing" and add payment method
     4. Purchase credits (minimum $5)
     5. Go to "API Keys" and click "Create Key"
     6. Copy the key (starts with "sk-ant-...")
     7. Save it somewhere safe

🎯 WHAT THIS TOOL DOES:

   INPUT:
   • Business requirements (what you need)
   • PLC tag list (what you have)
   • Optional documentation

   PROCESS:
   • AI analyzes and matches them
   • Gives confidence scores (0-100%)
   • Explains the reasoning

   OUTPUT:
   • Interactive results table
   • Accept/reject matches
   • Export to CSV or YAML

💰 ACTUAL COSTS (Updated):

   Per API Call (analyzing one requirement):
   • ~$0.01 to $0.05 per requirement analyzed
   • Example: 10 requirements = ~$0.10 to $0.50

   Minimum to Get Started:
   • You must purchase at least $5 in credits
   • This gives you roughly 100-500 analyses
   • Credits don't expire

   Cost Breakdown:
   • Input tokens: ~$3 per million tokens
   • Output tokens: ~$15 per million tokens
   • Typical analysis uses 1,000-3,000 tokens total

   ⚠️  You cannot use this tool without paying for API access!
